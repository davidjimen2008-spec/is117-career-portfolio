# Comparing career opportunities

**Question:** Which documented employer expectations should guide an early web-development portfolio?

| Dimension | NYT Frontend Intern | Priceline Junior Frontend Engineer |
|---|---|---|
| Career stage | 10-week summer internship | Full-time junior role |
| Work | Frontend products, cross-functional collaboration | High-traffic travel applications, performance, APIs |
| Overlap | React and collaborative development | React and collaborative development |
| Qualifications | Six months educational or professional frontend experience | CS bachelor's degree, JavaScript/TypeScript and framework experience |
| Deadline | Not stated | Not stated |
| Source | [NYT employer posting](https://job-boards.greenhouse.io/thenewyorktimes/jobs/4751909005) | [Priceline employer posting](https://priceline.wd1.myworkdayjobs.com/en-US/priceline/job/New-York/Junior-Software-Engineer_R5885) |

**Observed evidence:** Both postings mention React and cross-functional collaboration. Priceline also specifies API and responsive-design skills. Source pages were checked November 12, 2026.

**Interpretation / assumption:** A small responsive interactive project could demonstrate relevant skills, but neither employer promises that this project would satisfy its hiring requirements.

**Decision:** Prioritize an accessible, responsive project with JavaScript interactions, then add a React implementation and API integration as future work.

**Proposed verification:** Run the project at mobile and desktop widths, exercise all controls, document failures and fixes, and link commits and test evidence. **Status: planned, not yet performed.**
